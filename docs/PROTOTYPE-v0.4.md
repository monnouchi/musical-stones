# 3曲のオルゴールと、触れた光

2026-10-04、v0.4.0-local。本人の評価を受けたローカル候補。公開中のv0.3.0には変更していない。全体タイトル、3曲・2／3／4断片、自由配置と近傍吸着の操作を維持する。

## 曲と名前

| 曲 | 調・拍子・速さ | 形と命名理由 |
| --- | --- | --- |
| 芽吹く光 | C major、3/4、96 BPM、8小節 | 小さな呼びかけが姿を変え、高い返事と回帰へ伸びる「光」。音楽は承認済み1曲目そのまま。 |
| 水晶のこだま | G major、2/4、108 BPM、12小節 | B–D–Bの短い音型が反復し、高い返事を経て元の形へ戻る「こだま」。澄んだ、明るい2拍の曲。 |
| 月影の祈り | D minor、3/4、88 BPM、8小節 | D–F–Eの問いをD–E–F、E–G–Fへ変え、短調の影と静かな応答を持つ「祈り」。 |

1曲目はタイトルのみ変更。音列、和声、通常／完成の全イベント、BPM、音色、承認済みWAVは維持する。内部IDはsprout／walk／lanternと全断片IDを保つ。

2曲目は4小節の呼びかけ、4小節の高い返事、4小節の再現と終止。冒頭音型を1・3・9小節で反復する。中盤はG–B–Dから上へ伸び、7小節でG5へ。8小節のCから9小節のBへ応答し、最後はD7のF-sharpからGへ閉じる。

3曲目は2小節ずつの問い・応答・変奏・終止。Dm→A7、B-flat→Gm、E half-diminished→Gm、A7→Dm。C-sharpを属和音と旋律の導音に使い、最後はC-sharp→D、低音A→Dで短調の中心へ帰る。長い音の後に次の音を急いで差し込まず、自然な息継ぎを残す。

完成曲を小節単位で記述してから、自然なフレーズ境界で分割する。先に断片の音を無作為に作って並べない。新2曲はすべての小節頭に旋律と低音を置き、伴奏は2拍子なら低音→和音、3拍子なら低音→和音→和音。裏拍の八分音は拍内で終え、強拍をまたがせない。音価は四分・八分・二分・最後の長音を役割で使い、乱雑なシンコペーションや音価の差で個性を作らない。伴奏2音の小さな時間差は、音色を柔らかくする演奏上の広がりで、拍のアクセントは変えない。

音色は同じ独自合成のオルゴール。新しい第三者音源・既存曲の引用はない。完成版は旋律を変えず伴奏がそろう。WAVは同じエンジンの完成版、44.1kHz／16bit PCM／mono。長さは16.95／15.28／18.31秒（余韻と末尾の余白を含む）。

## 触る・置く光

pointerdownですぐ宝石の面が明るくなり、3粒の小さな光が出る。動く宝石DOMやpointer captureを変更しない。自由位置に置いた時も短い光が出る。台座では柔らかい波紋と、その時につながっている曲線への光の流れを加える。正解判定・解答データを参照しないので、誤順でも同じ反応になる。追加のSEは使わない。

光のDOMは合計18個まで、最長660msで削除。反復操作では古いものを先に捨てる。発光は各宝石に1タイマー、最長450ms。動くのは小さなtransform／opacityと短いSVGの線だけで、JSで毎フレーム追いかける処理はない。ドラッグの確定・取消、曲切替、シャッフル、クリア、全曲再生、明示停止、背景移行、リサイズで古い光・タイマー・アニメーションを解放する。

reduced-motionでは粒・波紋・線の移動・着床アニメーションを出さず、180msの静かな発光だけ。通常の試聴音、入力の追従、タップ／キーボード代替を維持する。
