# 自由配置と、新しい1曲のローカル試作

2026-10-04。公開版v0.2.1へのmonのレビューを受けた、v0.3.0-local。公開・pushは保留。まず1曲の試聴と、自由配置の検証までを今回の区切りとする。

## 宝石は自由な位置へ

`slots`は台座の順序だけ、`world[id] = {x,y}`は盤面内の相対位置だけを持つ。未配置の宝石を固定の棚へ戻す処理をなくした。ドラッグを離すと、その自由位置を保存する。台座から引き離した場合も同じ。盤面外で離すと安全な端で止め、元の固定位置へ戻さない。

吸着は台座の近傍だけ。横は最大38px（狭い画面では列間隔に合わせる）、縦は40pxの楕円範囲。外側では指の位置にそのままついてきて、近づくほど吸着の引力が強まり、離した時に台座へ収まる。元の宝石そのものを動かし、掴んだ位置と指の差を保つ。正しい台座だけに寄せる処理はない。

配置済み同士は台座を交換する。自由な宝石を占有台座へ入れると、元の宝石がその自由位置へ移る。どちらも消えない。接続の光は、台座に入った隣接宝石だけをつなぎ、正誤によらず同じ。

Esc・pointercancelは移動前へ戻す。リサイズ中は取消し、通知前に指が離れても寸法の変化を検知して古いドラッグ結果を確定しない。自由位置は相対座標で保存し、再読み込み・画面幅変更でも保持。現在の宝石サイズで端を制限する。旧形式の保存は移行し、作り直した1曲目の達成だけを解除、残り2曲は保持する。

タップで音を聴いてから、空いた盤面をタップしても移動できる。「はめる」は近い空き台座へ、「外す」は台座から外へ。左右ボタンは自由位置では移動、台座上では隣への移動・交換。矢印キーは自由移動、数字1〜4で台座へ、Shift＋左右で台座の交換、Deleteで外す。自由に重ね置きもでき、選択・キーボードフォーカスで宝石を前面にする。

## 1曲を、完成曲から作り直す

「ひとつの芽」を3/4、96 BPM、8小節（約17秒）として書き直した。モチーフMは E5–G5–A5–G5、短・短・長・長。区切りより先に8小節の曲を作り、最後に前半4小節の問いかけ／後半4小節の返事という自然なフレーズで2断片に分けた。

| 小節 | 旋律の骨格 | 和声と役割 |
| --- | --- | --- |
| 1 | E–G–A–G | C、Mを提示 |
| 2 | E–C–D–E | Am7、短い呼応 |
| 3 | D–F–G–F | Dm7、Mを全音下へ移調 |
| 4 | D–F–G–B | G7、最後だけ変えて問いかける |
| 5 | C–B–A–G | C、B→Cの解決と全曲の頂点 |
| 6 | E–G–A–G | Am7、Mがそのまま戻る |
| 7 | F–E–D–B | Dm7→G7、終止へ向かう |
| 8 | 長いC | C、主音と余韻で閉じる |

音価の無作為な変化や全曲を音階で埋める構成は使わない。前半の問いに後半が答え、同じモチーフを覚えて帰って来られる形を狙った。良い曲になったかは、実聴で判断してもらう。

音色はサンプルを使わず、短い立ち上がり、自然に減衰する基本音、早く消える上の成分を合成したオルゴール風。伴奏は3拍子の低音→小さな和音→小さな和音。完成時は同じ旋律を保ったまま伴奏がそろう。試聴WAVはゲームと同じWebAudioエンジンで、完成編曲をそのままレンダリングした。

残り2曲のデータは公開コミット`ac3ec56`と一致する。曲数・段階は3のまま。最初の曲の試聴結果が出る前に、残り2曲へ音色や作曲を横展開しない。
