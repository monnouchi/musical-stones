# 試作 v0.2 の設計

## 音を発掘してつなぐ

核は「聴く → 動かす → つなぎを聴く → 発見する」。ハーモニーカードのルールを持ち込まず、一から設計した独立した音楽パズル。仮タイトル「おとのつづき」。Happaと共同で作るサンプルとして、既存の2・3・4断片の3曲に集中する。

遺跡の石の台座と、音を宿す宝石を一つの場所に置く。タップで音が鳴り、宝石だけが光る。ドラッグで石のくぼみに近づけると位置に吸いつき、横に並んだ宝石の間を曲線の光がつなぐ。採掘ミニゲームや長い物語は追加しない。すべてのくぼみは共通形状で、色・輪郭・文字が正解位置を教えない。

## 曲と聴き分け

C-E-G-A、E-G-Eという初稿の動機を保ち、休符・反復・音価の差・応答を加える。単純な上昇下降の問題にせず、音が行き先を持つ短い曲へ。

初級は切片境界でB→Cを解決し、後半はii→V→Iで終わる。2・3曲目も山場から降りてV→Iへ帰着する。低音は一定の2拍間隔に加えてすべての和声境界で再発音し、次の根音までにリリースを終える。4.5拍／6.5拍の終止が抜ける問題を防いだ。

主旋律はB4〜C6、独自波形の倍音比1:.32:.14:.06:.025。音量だけを上げず、薄い和音・低音を後ろに置き、旋律の持続を残す。完成時は同じ旋律へ静かな2音の分散応答、少数の装飾、最後の主和音の.85秒の余韻を加える。通常と完成の旋律は一致する。完成の長さは約9.7／10.5／18秒。実スピーカーと初心者の実聴が、魅力・明瞭さ・難易度の判断には必要。

「このお手本を再構成する」を勝利条件とする。お手本は明示操作で何度でも聴け、断片順は光で漏らさない。色とA/Bの対応は無作為なセッション内識別に限る。隣接光・magnet・装飾は、判定前の正誤を表さない。

## 操作の確実さ

宝石のbuttonは曲を切り替えるまで同じDOMを使う。pointerdownでは再描画も試聴もしない。8pxの移動でドラッグへ切り替わり、pointer captureを保持する。プレビューは仮の配置で、離した時に一回だけ確定。移動中に宝石の見た目を動かしても保存状態は変更しない。

配置済み同士は交換。棚の宝石を占有くぼみへ入れると元の宝石が棚へ戻る。棚で離すと取り外し、台座外・隙間・Esc・pointercancelは取消。落とした時は音を鳴らさず、タップ試聴の冒頭をドラッグの着床で切らない。クリックの重複を抑える。くぼみ・棚の見た目と、位置だけを示す静かな光で操作を理解できるようにする。

タップ→「はめる」、左右ボタン、戻す、数字キー、矢印キー、Deleteで同じ操作を提供する。主要タッチ対象は44 CSS px以上。通常文字では390×844、390×664、320×568の宝石・お手本・判定・停止が同時に見える。文字拡大では折り返しと縦スクロールを許可する。

## 完成・音声・復帰

正しい並びを置くだけでは完成演出を開かない。「よみがえらせる」で判定後、薄暗い鑑賞画面が開き、すべての宝石が同時に静かに輝く。五線風の背景がゆっくり揺れ、一曲を聴ける。停止・音量・ミュート、Escで閉じる操作を残し、閉じると元のボタンにフォーカスが戻る。配置を編集すると完成の認定は解除し、再判定を待つ。

音声は最初の明示操作で作る。世代番号で遅いresume後の誤再生を防ぎ、停止は18msフェード・22ms後に発音停止、onendedで接続を解放する。背景移行で停止・suspend、戻っても自動再生しない。自然終了・失敗でも鑑賞画面を閉じる。音量・配置・達成は検証付きlocalStorageで保存し、保存不可でも遊べる。

動きを減らす設定ではアニメーションと移動transitionを止め、静的な光・音・操作は維持する。新しい曲や物語の追加はせず、monの初回体験と集中レビューを踏まえてこの3曲を調整する。
