# v0.2 重点レビュー

2026-10-04、対象の開始コミット`ae84800`。基準は「完成曲そのものの魅力 → 宝石の直接操作 → 遺跡の中で音楽がよみがえる」。曲数・段階は2／3／4断片の3曲のまま。

## 音楽

既存のC-E-G-A、E-G-Eの動機を保ち、反復・休符・音価の差、山場からの帰着を確認。初級の切片境界はB→Cで解決。終止の低音は和声境界にも発音し、2曲目4.5拍／3曲目6.5拍のCを含めて指定が実行される。通常と完成の旋律は一致し、完成時だけ静かな分散伴奏と応答音、主和音の余韻がある。

3曲目の第3断片は、前のB5からC6へ到達する山場。その冒頭の低音をE3からC4へ変え、上のE-G-Bと合わせてCmaj7とし、旋律の解決先に主音を置いた。動機や順序は変更していない。

音列・和声・波形の検証は、接続／終止の設計とデジタル出力を支持する。音楽の魅力や物理スピーカーの聴き心地を実聴で確定したものではない。monの初回プレイが引き続き必要。

## 宝石・くぼみ・光

旧カードの選択と別の矩形配置ボタンは取り除かれている。同じ宝石buttonが棚からくぼみへ直接移動し、曲が同じ間は同じDOMとpointer captureを維持する。くぼみは共通の宝石形で、位置だけを示す磁石の光が出る。どの宝石もどのくぼみに入り、色と文字は無作為な識別。

矩形の石の台座と操作ボタンは残るが、中心操作はその上の宝石の移動。隣り合う宝石の曲線は、正順と誤順で同じSVGと描画になる。仮配置を表示しても保存状態は変わらず、離す時だけ確定する。取消・棚へ戻す・交換・キーボードでの配置が同じ状態を操作する。

タップは離した時に一度試聴。8px以上の移動でドラッグへ切り替える。ドラッグを開始すると前の音をフェード停止し、着床では新しい試聴を始めない。試聴の冒頭を落とした瞬間に切る競合を防ぐ。ドラッグ途中のキーボード配置は、先にドラッグを取消してから確定するよう修正し、その後のpointerupが古い配置を上書きしないことを実Chromeで確認した。

## 正解前と完成後

空穴は飛ばして、置いた音だけを左から再生する。これはhelpと再生状態で示す。正しい並びでも「よみがえらせる」で明示判定するまでは完成編曲・鑑賞画面を開かない。お手本は断片の発光を使わず、正解順を漏らさない。

完成時は暗い鑑賞画面に全宝石が同時に静かに輝き、同じ主旋律に分散伴奏が開く。五線風の背景は21秒周期の穏やかな動き。停止・Esc・自然終了・背景移行で閉じ、元へ戻る。停止・音量・消音を常に操作できる。reduced-motionではCSSの動きも、JSの短い着床発光も抑え、音と静的な光は残る。

## 小画面

390×844／390×664／320×568の全3曲で、スクロール位置0から主要操作が表示される。320pxでも主操作14px、説明13pxに拡大し、説明を短くした。曲名と達成チェックを別行にし、チェックの追加で曲名の途中が折り返されにくい配置へ。拡大文字は折り返し・台座の拡張・縦スクロールを許可する。

80項目の通し操作、native touch16項目、重点項目17件、Node19テストと6編曲の実WebAudioを検証。デジタル出力にNaN・クリッピングなし、停止後133発音が終了し管理ノード0。物理端末や初心者の実聴は未確認。

重大な実装上の未解決は見つからなかった。本人の公開承認に従い、現在のpublic／main／rootのPages設定へ通常pushする。公開時はexact commit、Pages workflow、ライブ配信の主要ファイル一致と実Chromeの開始・試聴・完成・停止を確認する。
