# Musical Stones

[ゲームで遊ぶ](https://monnouchi.github.io/musical-stones/) · [3曲を試聴する](https://monnouchi.github.io/musical-stones/review/)

音の宝石を聴いて並べ、遺跡に眠る小さな曲をよみがえらせる音楽パズルです。スマートフォン・PCで遊べ、楽譜の知識は要りません。

## 遊び方

1. 「お手本」で完成した曲を聴きます。
2. 宝石をタップして音の断片を聴き、五線のくぼみに左から並べます。
3. 「並びを聴く」でつながりを試し、「よみがえらせる」で判定します。正解すると宝石が輝き、完成した曲を楽しめます。

| 曲 | 宝石の数・難度 |
| --- | --- |
| 芽吹く光 | 2個・入門 |
| 水晶のこだま | 3個・中級 |
| 月影の祈り | 4個・上級 |

曲は自由に選べます。色と音A〜Dは識別用で、答えを示しません。どの宝石もすべてのくぼみに入ります。空のくぼみは飛ばして再生します。

## 操作

宝石をドラッグして近くのくぼみにはめます。配置済みの宝石同士は交換でき、引き離すと外せます。自由な場所にも置けます。

ドラッグを使わない場合は、宝石を選んで盤面をタップするか、「はめる」「←」「→」「外す」を使います。

| キー | 操作 |
| --- | --- |
| Tab、Enter / Space | 宝石・ボタンへ移動、試聴・実行 |
| 矢印キー | 宝石を自由に移動 |
| 1〜4 | 選んだ宝石を指定のくぼみへ |
| Shift＋左右 | 台座上で隣へ移動・交換 |
| Delete / Backspace | 台座から外す |
| P / S / Esc / M | 並びを再生／停止／停止・ドラッグ取消／消音切替 |

## 音・保存・やり直し

音は操作したときだけ鳴ります。音量・消音・停止を調整でき、画面を離れると停止します。戻っても自動再生しません。完成後の鑑賞画面にも停止ボタンがあります。「動きを減らす」設定では、回転せず静かに輝きます。

プレイ中は曲を切り替えても配置を保持します。再読み込みや次回の起動では、全曲の台座を空にして宝石をシャッフルし、最初から遊べます。音量・消音・選択中の曲だけは保存します。

「宝石の動かし方・曲のヒント」を開くと、「シャッフルしてやり直す」で現在の曲を最初から、「すべて外す」で配置だけを外せます。配置を変えると完成時の輝きは解除されます。

JavaScriptとWeb Audioに対応したブラウザーで開いてください。拡大文字ではスクロールして操作できます。ブラウザーが保存を制限する場合、設定は次回に引き継がれません。
