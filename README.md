# おとのつづき（仮）

GitHub Pages 向けの静的な音楽パズル試作です。短いオリジナル曲を断片に分け、聴き比べながらお手本と同じ順序へ並べます。完成すると伴奏が加わり、一曲として鳴ります。楽譜・音名・音楽理論の知識は不要です。

## ローカルで遊ぶ

Node.js 20 以降で、依存パッケージのインストールは不要です。

```sh
npm start
```

<http://127.0.0.1:4187/demo5/> を開いてください。ルートの <http://127.0.0.1:4187/> でも動作します。音は再生ボタンを押したときだけ鳴ります。終了はサーバーのターミナルで Ctrl+C。

ポートを変更する場合：

```sh
PORT=4188 npm start
```

Python など任意の静的 HTTP サーバーでも動作します。ES modules を使用するため、`file://` で直接開かず HTTP で起動してください。

## 遊び方

1. 「お手本を聴く」で完成する曲を聴く。何度でも利用できます。
2. 各かけらの「聴く」で音を確かめる。
3. 「選ぶ」→置き場所で配置する。配置済みの音を選び、別の場所を押すと交換できます。×で外せます。
4. 「並びを聴く」で試す。空きがあるときは配置済みの音を順番に続けて再生します。
5. 全部配置したら「完成をたしかめる」。正解時は伴奏が広がり、次の曲へ進めます。制限時間や失敗回数のペナルティはありません。

タップ、マウス、キーボードで同じ操作ができます。ドラッグ操作は不要です。

| キー | 操作 |
| --- | --- |
| Tab / Shift+Tab | ボタンへ移動 |
| Enter / Space | フォーカス中のボタン操作 |
| 1〜4 | 選択した音を対応する置き場所へ配置 |
| P | 現在の並びを再生 |
| S | 停止 |
| M | ミュート切り替え |
| Esc | 選択解除と停止 |

音量のスライダーなど入力欄を操作中は、全体ショートカットを無効にします。音量、ミュート、各曲の配置と達成状況は、このブラウザーの localStorage に保存します。保存不可でも遊べます。画面を離れると停止し、復帰や再読み込みでは自動再生しません。

## 3つの小さな曲

| 曲 | 断片数 | 全曲の長さ | 聴くポイント |
| --- | --- | --- | --- |
| ひとつの芽 | 2 | 約4.8秒 | 上がる呼びかけと、落ち着く返事 |
| 窓辺のさんぽ | 3 | 約9.6秒 | 同じ音型の発展、上昇から帰着 |
| 灯りの帰り道 | 4 | 約16秒 | 高い山場、下り、最後の余韻 |

曲は本試作のために作成した独自の音列と伴奏です。既存曲の引用、第三者の音源、サンプル、音楽配信サービスは使いません。Web Audio API の三角波・正弦波で音を合成します。外部フォントや CDN も使いません。

正解は「お手本の再構成」として定義しています。別の順序も音楽として成立し得るため、「気持ちよさ」だけで厳密な判定はしません。A/B/C/D は毎回の新規ゲームでランダムに割り当てる識別子です。すべて同じ色・形を使い、正解順に対応する文字・長さ・楽譜は表示しません。お手本の再生中にも断片の順序をハイライトしません。

「シャッフル」は全かけらをランダムに配置します。シャッフルだけで完成扱いにならないよう、解答と同じ並びを避けます。特に2断片の問題は組み合わせが少ないため、入門として位置付けています。

## GitHub Pages 向け構成

`index.html`、`style.css`、`src/`、`assets/`、`.nojekyll` が配信に必要なファイルです。相対 URL だけを使い、プロジェクトの `/demo5/` 配下でも動作します。ビルド工程、バックエンド、環境変数、外部 API は不要です。

リポジトリの Pages 設定・可視性は変更していません。自動公開 workflow も追加していません。初回体験の方向を確認したあと、必要であれば GitHub の Pages 設定で承認したブランチのルートを配信対象にできます。現在の成果はローカルのみです。

## 検証

```sh
npm test
npm run check
```

Node 標準テストで判定、交換、シャッフル、保存復元、破損データ、音声スケジューリングの停止・競合・背景復帰を確認します。

実 Chrome QA 用の任意のスクリプトも `scripts/` にあります。実行には Playwright CLI と Google Chrome が必要です。アプリ自体の依存ではありません。

```sh
playwright-cli -s=demo5-music open http://127.0.0.1:4187/demo5/ --config=scripts/chrome-qa.config.json
playwright-cli -s=demo5-music snapshot
playwright-cli -s=demo5-music run-code --filename scripts/browser-qa.js
playwright-cli -s=demo5-music run-code --filename scripts/mobile-qa.js
playwright-cli -s=demo5-music close
```

最初の QA は新規の隔離セッションで実行してください。生成されたスクリーンショット・ログは `output/playwright/` に保存し、Git の対象から除外しています。検証結果と制約は [docs/QA.md](docs/QA.md)、設計意図は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。
